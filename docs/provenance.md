# Provenance and release boundary

Created 6 November 2026 as a separate portfolio project. The user authorized
starting a CPU/MPI project while preserving original coursework. This implementation
uses the publicly known heat equation and explicit finite differences, with the
full mathematical specification written here. No archived coursework source was
copied or adapted into this repository. Development writes are confined to this
project directory; recovered EIDF/Cirrus/ARCHER2 and Blackboard archives are untouched.

C standard-library facilities and an installed MPI runtime are external dependencies.
Python tests and benchmark tooling use the standard library. The workflow references
GitHub's checkout and artifact-upload actions at fixed revisions. No data assets or third-party source
are bundled. The project is licensed under the [MIT License](../LICENSE), selected
by the owner on 6 November 2026. This license covers the project files, not the
separate university archives or external dependencies.
